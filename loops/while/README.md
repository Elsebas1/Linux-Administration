# WHILE

The `while`loop is a flow control structure that repeatedly executed a block of code as long as a specific condition is evaluates to True. Unlike `for`loop, the `while`loop is indeterminated; it is used when the number of required iterations is not known with certainly. Its execution depends on the state of the system or the program.
